# RegretLens

後悔を予測し分析する機械学習ベースの意思決定支援システム

## 概要

RegretLensは、ユーザーの意思決定における後悔を理解・軽減するのに役立つFlaskベースのWebアプリケーションです(このコードではダミーデータが作成されます)：

- **ML後悔予測**: ランダムフォレストを使用した個人適応型の後悔予測
- **パターン分析**: 意思決定履歴から繰り返される後悔パターンを検出
- **コンテキスト分析**: 感情状態、予算、ストレスレベルなどに基づいた個人化された警告
- **研究フレームワーク**: モデル評価とA/Bテスト機能

## 主な機能

### 1. 意思決定記録
- カテゴリと代替案を含む意思決定をログ
- 決定要因を記録（価格、健康価値、所要時間など）
- 感情・環境コンテキストを記録（気分、ストレス、空腹度、天気など）

### 2. 後悔予測
- **ハイブリッドアプローチ**: 機械学習とルールベースのフォールバック
- **個人適応モデル**: ユーザーごとに個別モデルを訓練
- **リアルタイム警告**: 高リスク意思決定パターンを検出
- **類似ケース検出**: 類似した過去の決定と結果を表示

### 3. フィードバック・分析
- 意思決定後の後悔フィードバックを記録
- 満足度スコアと具体的な後悔理由を追跡
- 履歴データから自動的にパターンを検出
- カテゴリ別・時間別の後悔分析

### 4. 研究機能
- 時系列交差検証によるモデル評価
- MLモデル（Random Forest、XGBoost）とルールベースの比較
- 後悔削減率（RRR）の計算
- モデル性能指標（MAE、RMSE、R²など）

## 技術スタック

- **バックエンド**: Flask（Python）
- **データベース**: PostgreSQL
- **機械学習**: scikit-learn、XGBoost
- **解釈可能性**: SHAP
- **データ処理**: NumPy、SciPy

## インストール

### 環境
- Python 3.8以上
- PostgreSQL 12以上

### セットアップ

1. **リポジトリをクローン**
```bash
git clone https://github.com/yourusername/regretlens.git
cd regretlens
```

2. **仮想環境を作成**
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

3. **依存パッケージをインストール**
```bash
pip install -r requirements.txt
```

4. **環境変数を設定**
```bash
cp .env.example .env
# .envファイルを編集して設定を入力
```

5. **データベースをセットアップ**
```bash
# PostgreSQLデータベースを作成
createdb senmon3

# テーブルを作成（スキーマファイルをプロジェクトに追加してください）
psql senmon3 < schema.sql
```

6. **アプリケーションを実行**
```bash
python myapp.py
```

ブラウザで `http://localhost:5000` にアクセスしてください。

## MLモデル

### 予測パイプライン

1. **特徴量抽出**
   - 決定要因（価格、味、健康度、時間）
   - コンテキスト特徴量（気分、ストレス、空腹度、予算）
   - 時間特徴量（時刻、曜日、昼食時間帯など）
   - 天気と社会的コンテキスト
   - ユーザー履歴特徴量（過去の後悔率、トレンド）

2. **モデル訓練**
   - **最小データ要件**: 10件のフィードバックサンプル
   - **方法**: ランダムフォレスト回帰（50推定量、max_depth=10）
   - **特徴量**: 18次元
   - **ターゲット**: 後悔スコア（0-1スケール）

3. **予測出力**
   - 後悔スコア（0-1）
   - リスクレベル（低/中/高）
   - 個人化された警告
   - 類似過去ケース
   - 予測方法（MLまたはルールベース）

### ルールベースフォールバック

## 主要なアルゴリズム

### 適応的特徴量選択
- **方法**: SHAP、Permutation Importance、RFE、SelectKBest
- ユーザーごとに最も関連性の高い特徴量を自動検出
- 個人適応型特徴量セットで過学習を削減

### パターン分析
- パターン種類：高ストレス決定、高額購入、低期待値選択、曜日別パターンなど
- 最小2回の発生でパターンを保存
- 平均後悔度と発生回数を追跡

### モデル評価
- **時系列交差検証**: データの時間順序を尊重
- **指標**: MAE、RMSE、R²、Accuracy、Precision、Recall、F1
- **比較**: MLとルールベースの比較
- **統計検定**: 後悔削減の有意性をt検定で検証

## 使用例

### 個人ユーザー向け

1. **意思決定を記録**
   - 「新規意思決定」に移動
   - カテゴリを選択し、選択肢を説明
   - コンテキスト情報を入力（気分、ストレス、予算など）
   - 決定要因を入力（価格、期待度など）
   - 後悔予測を受け取る

2. **結果を追跡**
   - 意思決定後に「フィードバック」に戻る
   - 後悔度と満足度を評価
   - 具体的な後悔理由を記載
   - システムがパターンを分析

3. **インサイトを確認**
   - ダッシュボードで主な後悔パターンを確認
   - 週間後悔トレンドを表示
   - 高リスク状況を特定

### 研究者向け

1. **実験をセットアップ**
   - 意思決定とフィードバックデータを収集
   - `/research/evaluate` にアクセス
   - 比較方法を選択

2. **評価を実行**
   - MLとルールベースの性能を比較
   - モデル指標を分析
   - 統計レポートを生成

3. **結果をエクスポート**
   - 結果は `evaluation_results/` に保存
   - JSON形式で追加分析に使用可能

## モデル性能

システムが提供する包括的な指標：
- **MAE/RMSE**: 連続予測の精度
- **R²**: モデルが説明する分散の比率
- **分類指標**: リスク分類のAccuracy、Precision、Recall、F1
- **後悔削減率（RRR）**: システムが実際の後悔に与える影響

## 注意事項

### データ要件
- ML モデル訓練には最小 10 件のフィードバックサンプルが必要
- より安定したモデル（30件以上推奨）
- 時系列分析のため時間データを保持

### 制限事項
- デフォルトでシングルユーザーセットアップ（FIXED_USER_ID）
- PostgreSQL が必須（DB非依存ではない）
- ユーザーごとにMLモデルを訓練（縦断的個人データに適している）
