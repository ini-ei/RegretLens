実験1: モデル性能比較
目的
提案手法（Random Forest + 適応的特徴量選択）が既存手法より優れていることを示す
比較対象

ルールベースのみ - 既存手法
Random Forest（全18特徴量） - ベースライン
Random Forest + 適応的特徴量選択（12特徴量） - 提案手法
XGBoost（全18特徴量） - 比較用（オプション）

データ生成

ユーザー数: 100名

ストレス敏感型: 30名（30%）
価格敏感型: 30名（30%）
気分依存型: 20名（20%）
ランダム型: 20名（20%）


決定数/ユーザー: 100件（約3ヶ月分の日次データ）
総決定数: 10,000件
訓練/テスト分割: 80件/20件（時系列順守）

ユーザータイプ詳細
ストレス敏感型（30名）

ストレスレベル≥4で後悔率が急増
高ストレス × 高額購入で特に後悔
パラメータ:

stress_sensitivity: 0.8～1.0
baseline_regret: 0.2～0.3


後悔計算: baseline + stress_level × 0.35 + price/2000 × 0.15

価格敏感型（30名）

価格1000円以上で後悔率上昇
予算残高が少ない時に特に敏感
パラメータ:

price_sensitivity: 0.8～1.0
baseline_regret: 0.2～0.3


後悔計算: baseline + price/2000 × 0.45 + (予算不足) × 0.2

気分依存型（20名）

気分スコアが低いと何をしても後悔
天気・曜日の影響大
パラメータ:

mood_sensitivity: 0.8～1.0
baseline_regret: 0.2～0.3


後悔計算: baseline + (5-mood_score) × 0.35 + (雨/月曜) × 0.15

ランダム型（20名）

明確なパターンなし
ノイズが大きく予測困難
パラメータ:

すべてのsensitivity: 0.3～0.7（ランダム）
baseline_regret: 0.3～0.5


後悔計算: baseline + 各要因 × 0.1 + random_noise(-0.2, 0.2)

コンテキスト生成ルール

時刻: ランチタイム（11-13時, 40%）、ディナー（18-20時, 30%）、その他（30%）
曜日: 連続100日間の実日付（2025年8月1日開始）
気分スコア: 正規分布（平均3, 標準偏差1）、月曜-0.5、雨-0.5
ストレスレベル: 正規分布（平均3, 標準偏差1.2）、月火+0.5、月末+0.8、夜+0.7
空腹度: 食事時間前は平均4、その他は平均3
天気: 晴れ50%、曇り30%、雨15%、雪5%
予算残高: 月初7000-10000円、月中4000-7000円、月末1000-4000円
同伴者: 一緒30%、一人70%

決定要因生成ルール

カテゴリ: 食事40%、買い物30%、娯楽15%、学習10%、仕事5%
価格:

食事: 正規分布（平均800円, 標準偏差300, 範囲400-2000）
買い物: 対数正規分布（中央値1500円, 範囲500-5000）
娯楽: 正規分布（平均1500円, 標準偏差500, 範囲800-3000）


期待度: 正規分布（平均3.5, 標準偏差0.8）、高価格なら+0.5～1.0
健康価値: カテゴリ依存（食事: 平均3、学習: 4）
所要時間: カテゴリ依存（食事: 平均40分、娯楽: 平均120分）

評価指標

MAE (Mean Absolute Error) - 主指標
RMSE (Root Mean Squared Error)
R² Score
統計的有意性: t検定（提案手法 vs Random Forest）

期待される結果
ルールベース:           MAE = 0.25 ± 0.05
Random Forest (全特徴): MAE = 0.18 ± 0.04
提案手法 (RF + 適応):   MAE = 0.15 ± 0.03  ← 15%改善
XGBoost:                MAE = 0.17 ± 0.04

統計的有意性: p < 0.01
```

### 出力グラフ
1. **棒グラフ**: 各手法のMAE比較（エラーバー付き）
2. **箱ひげ図**: 100ユーザーのMAE分布

## 実験2: 適応的特徴量選択の効果

### 目的
個人化（ユーザーごとに特徴量を選ぶ）の有効性を示す

### 比較対象
1. **全18特徴量使用** - すべてのユーザーで同じ18特徴量
2. **固定上位12特徴量** - 全ユーザーの平均で重要度が高い12特徴量（個人化なし）
3. **適応的12特徴量** - ユーザーごとにSHAP値で選択（個人化あり）← 提案手法

### データ生成
- **ユーザー数**: 50名
  - 各タイプ均等: ストレス敏感12名、価格敏感13名、気分依存13名、ランダム12名
- **決定数/ユーザー**: 100件
- **総決定数**: 5,000件
- **訓練/テスト分割**: 80/20

### 実験プロセス
1. 各ユーザーの訓練データ（80件）で特徴量重要度を計算
2. 3つの手法で特徴量を選択:
   - 全18特徴量: すべて使用
   - 固定12特徴量: 全50ユーザーの平均SHAP値で上位12個
   - 適応12特徴量: 各ユーザーのSHAP値で上位12個
3. テストデータ（20件）で予測精度を評価

### 評価指標
- **MAE** - 主指標
- **特徴量の多様性**: ユーザー間でどれだけ選択された特徴量が異なるか
  - Jaccard距離の平均
  - ユニーク特徴量セットの数
- **タイプ別の改善率**: 各ユーザータイプでの適応的選択の効果

### 期待される結果
```
全18特徴量:        MAE = 0.18 ± 0.04
固定上位12特徴量:  MAE = 0.17 ± 0.04
適応的12特徴量:    MAE = 0.15 ± 0.03  ← 最良

特徴量多様性:
- ストレス敏感型: 主に stress_level, price が選ばれる
- 価格敏感型: 主に price, budget_remaining が選ばれる
- 気分依存型: 主に mood_score, weather, day_of_week が選ばれる
→ ユーザータイプによって重要な特徴量が異なることを示す
```

### 出力グラフ
1. **棒グラフ**: 3手法のMAE比較
2. **ヒートマップ**: ユーザー（縦軸50名）× 特徴量（横軸18個）の重要度
   - ストレス敏感型は stress_level が赤く（重要）
   - 価格敏感型は price が赤く
   - → ユーザーごとに重要な特徴量が違うことを視覚化
3. **テーブル**: ユーザータイプ別の主要特徴量Top5

## 実験3: 時系列学習の効果

### 目的
過去のシーケンスを考慮する効果を示す

### 比較対象
1. **Random Forest（単発予測）** - 1件ずつ独立に予測
2. **LSTM（シーケンス予測）** - 過去10件から予測
3. **LSTM + Attention** - 重要な過去を強調 ← 提案手法

### データ生成
- **ユーザー数**: 30名
  - 各タイプ均等
- **決定数/ユーザー**: 200件（約6ヶ月分の長期データ）
- **総決定数**: 6,000件
- **訓練/テスト分割**: 160/40
- **シーケンス長**: 10件

### 時系列パターンの設計
通常の仮想データに加えて、以下の時系列パターンを埋め込む:

1. **週末の衝動買いパターン**
   - 金曜夜～日曜: 価格が20%高くなる傾向
   - 週末の後悔率が10%上昇

2. **月末の予算逼迫パターン**
   - 25日以降: 予算残高が急減
   - 安い選択肢を選ぶが後悔率が上昇（我慢の反動）

3. **疲労蓄積パターン**
   - 連続3日間決定があると: ストレスレベル+1
   - 連続5日間だと: ストレスレベル+2、後悔率20%上昇

4. **月曜憂鬱パターン**
   - 月曜: 気分-1, ストレス+1
   - 月曜の決定の後悔率が15%上昇

### 評価指標
- **MAE** - 時系列後半（テスト期間）での予測精度
- **時系列での精度変化**: 週ごとのMAE推移
- **Attention重みの可視化**: どの過去決定が重要視されたか

### 期待される結果
```
Random Forest:    MAE = 0.18 ± 0.04
LSTM:             MAE = 0.16 ± 0.03  ← 時系列考慮で改善
LSTM + Attention: MAE = 0.14 ± 0.03  ← 最良

時系列精度:
- データ初期（0-50件）: どの手法も MAE 0.22程度
- データ中期（50-100件）: LSTMが改善し始める（MAE 0.18）
- データ後期（100件以降）: LSTM+Attnが安定（MAE 0.14）

Attention重み:
- 例: 「3週間前の同じ店での失敗」に高い重み
- 例: 「先週末の衝動買い」に高い重み
```

### 出力グラフ
1. **折れ線グラフ**: 時間経過（週）とMAEの変化
   - 3本の線（RF, LSTM, LSTM+Attn）
   - LSTMが時間とともに改善していく様子を示す

2. **ヒートマップ**: Attention重みの可視化
   - 横軸: 過去10件の決定
   - 縦軸: テストケース5個
   - 色: Attention重み（赤=重要、青=無視）
   - 例: 「ケース1は3件前の決定を強く参照している」

3. **棒グラフ**: 3手法のMAE比較

## 実験4: ユーザータイプ別の予測精度

### 目的
どんな後悔タイプでも予測できることを示す

### データ生成
- **実験1と同じデータを使用**
- ユーザータイプ別に精度を分析

### 評価
各タイプでの提案手法（RF + 適応的特徴量選択）の予測精度を比較

### 期待される結果
```
ストレス敏感型:  MAE = 0.12  ← パターン明確で予測しやすい
価格敏感型:      MAE = 0.13
気分依存型:      MAE = 0.14
ランダム型:      MAE = 0.22  ← パターンなしで予測困難

結論:
- 明確なパターンを持つユーザーでは高精度
- ランダム型でも MAE 0.22 は実用的範囲
```

### 出力グラフ
1. **箱ひげ図**: タイプ別のMAE分布
2. **テーブル**: タイプ別の統計量（平均MAE, 標準偏差, 最良/最悪ケース）
```
