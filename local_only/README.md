# RegretLens - 後悔予測システム

日常の意思決定を記録し、後悔のパターンを学習して将来の意思決定をサポートするWebアプリケーション

## 概要

RegretLensは、ユーザーの意思決定履歴とその結果のフィードバックを記録・分析することで、後悔しやすい選択パターンを可視化し、より良い意思決定をサポートするシステムです。

### 主な機能

- **意思決定の記録**: カテゴリ、内容、代替案、コンテキスト（気分、ストレスレベル、天気など）を詳細に記録
- **リアルタイム後悔予測**: 入力中の意思決定に対して、過去のパターンから後悔リスクをスコアで予測
- **詳細な警告メッセージ**: なぜ後悔しやすいのか、具体的な理由を提示
- **類似ケース提示**: 過去の類似した意思決定と結果を表示
- **フィードバック収集**: 意思決定後の後悔度・満足度を複数のタイミングで記録
- **統計ダッシュボード**:
  - 後悔しやすいパターン Top 3 の可視化
  - カテゴリ別後悔率のグラフ表示
  - 週ごとの後悔率推移の可視化
- **パターン分析**: フィードバックから自動的に後悔パターンを抽出・学習

## 技術スタック

- **フロントエンド**: HTML, CSS, JavaScript (Jinja2テンプレート)
- **バックエンド**: Flask (Python 3.x)
- **データベース**: PostgreSQL
- **認証**: Flask Session + Werkzeug Security
- **予測エンジン**: ルールベース + 統計的手法

## 使用方法

### 1. ユーザー登録

1. `/register` にアクセス
2. メールアドレスとパスワード（6文字以上）を入力して登録

### 2. ログイン

1. `/login` にアクセス
2. 登録したメールアドレスとパスワードでログイン

### 3. 意思決定の記録

1. ダッシュボードから「新しい意思決定を記録」をクリック
2. 以下の情報を入力：
   - **基本情報**: カテゴリ、決定内容、代替案
   - **コンテキスト**: 気分、ストレスレベル、空腹度、時刻、曜日、天気、同伴者の有無、残予算
   - **決定要因**: 価格、期待値、健康への影響、所要時間
3. **「💡 後悔リスクを予測」ボタン**をクリックすると、リアルタイムで予測結果を表示
   - 後悔スコア（0-100%）
   - リスクレベル（高/中/低）
   - 注意すべきポイント
   - 過去の類似ケース
4. 「記録する」で保存（予測スコアも自動保存）

### 4. フィードバックの入力

1. ダッシュボードから過去の意思決定の「フィードバック」ボタンをクリック
2. 以下を入力：
   - 後悔度（1-5）
   - 満足度（1-5）
   - やり直したいか
   - フィードバック時期
   - 後悔の理由
3. 送信すると、自動的に**後悔パターン分析**が実行され、ダッシュボードに反映

### 5. ダッシュボードでの分析確認

- **統計サマリー**: 総意思決定数、フィードバック数
- **後悔しやすいパターン Top 3**: 自動検出されたパターンと発生回数
- **カテゴリ別後悔率**: プログレスバーで視覚的に表示
- **週ごとの後悔率推移**: グラフで時系列変化を確認
- **最近の意思決定一覧**: 予測スコアと実際の結果

## データベーススキーマ

### users テーブル
- `id`: UUID (主キー)
- `email`: メールアドレス (ユニーク)
- `password_hash`: パスワードハッシュ
- `created_at`: 作成日時

### decisions テーブル
- `id`: UUID (主キー)
- `user_id`: ユーザーID (外部キー)
- `category`: カテゴリ (食事、買い物、仕事など)
- `decision_text`: 意思決定の内容
- `alternatives`: 代替案 (JSONB配列)
- `context`: コンテキスト情報 (JSONB: 気分、ストレス、天気など)
- `decision_factors`: 決定要因 (JSONB: 価格、期待値など)
- `predicted_regret_score`: 予測された後悔スコア (0.0-1.0)
- `created_at`: 作成日時

### feedbacks テーブル
- `id`: UUID (主キー)
- `decision_id`: 意思決定ID (外部キー)
- `regret_score`: 後悔度 (1-5)
- `satisfaction_score`: 満足度 (1-5)
- `regret_reasons`: 後悔の理由 (JSONB配列)
- `would_change`: やり直したいか (Boolean)
- `feedback_timing`: フィードバック時期 (直後、1日後など)
- `created_at`: 作成日時

### regret_patterns テーブル
- `id`: UUID (主キー)
- `user_id`: ユーザーID (外部キー)
- `pattern_type`: パターンタイプ (例: "高ストレス時の食事選択")
- `trigger_conditions`: トリガー条件 (JSONB)
- `average_regret`: 平均後悔度
- `occurrence_count`: 発生回数
- `created_at`: 作成日時
- `updated_at`: 更新日時

## 後悔予測アルゴリズム

### 特徴量
- **決定要因**: 価格、期待値、健康価値、所要時間
- **コンテキスト**: 気分、ストレスレベル、空腹度、時刻、曜日、天気、同伴者、残予算
- **ユーザー履歴**: 同カテゴリの平均後悔度、分散、類似決定数、最近のトレンド

### 予測ロジック
1. ベーススコア: 0.3
2. リスク要因を加算：
   - 高ストレス（≥4）: +0.2
   - 高価格（>1000円）: +0.15
   - 過去の高後悔率（≥4）: +0.25
   - 最近の高後悔トレンド（≥4）: +0.15
   - 低期待値（≤2）: +0.2
   - 低気分（≤2）: +0.1
   - 高空腹度（≥5）: +0.15
   - 予算超過: +0.2
3. 最終スコア = min(1.0, max(0.0, 合計))

### パターン分析
フィードバック登録時に自動実行：
- 高ストレス時のカテゴリ別後悔パターン
- 高額購入時の後悔パターン
- 低期待値選択の後悔パターン
- 曜日×カテゴリ別の後悔パターン

2回以上発生したパターンのみデータベースに保存し、ダッシュボードに表示。

## セキュリティ上の注意

1. **パスワード**: Werkzeug の `generate_password_hash` でハッシュ化
2. **セッション**: Flask Session でログイン状態を管理（セッションキーは安全な乱数で設定済み）
3. **SQL インジェクション対策**: パラメータ化クエリを使用
4. **本番環境**: DEBUG モードをオフにすることを推奨

## システムの独自性

### 1. 日常的マイクロ意思決定への特化
- 既存研究: 投資・医療など大きな決定
- 本システム: ランチ選び、衝動買いなど日常の小さな選択に特化

### 2. 予測型アプローチ
- 既存システム: 事後の振り返りのみ
- 本システム: 意思決定時点で後悔を予測し警告

### 3. パーソナライズされた学習
- 既存研究: 一般的な後悔パターン
- 本システム: 各ユーザーの個別の後悔傾向を機械学習で抽出

## トラブルシューティング

### データベース接続エラー
- `setup.sql` が正しく実行されているか確認
- データベース接続情報（ホスト、DB名、ユーザー、パスワード）を確認

### 予測機能が動作しない
- ブラウザのJavaScriptが有効になっているか確認
- ブラウザのコンソールでエラーを確認

### パターンが表示されない
- フィードバックを2件以上登録しているか確認
- 後悔度が3以上のフィードバックがあるか確認
